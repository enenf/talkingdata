# 销售分析报告（2026-09 至 2026-11）

数据源：`uploads/sales.csv`（6 条记录，2 个渠道）。计算脚本 `scripts/analyze_sales.py`，明细 `artifacts/summary.csv`。

## 一、口径

- 毛利 = 收入 − 成本；毛利率 = 毛利 ÷ 收入；客单价 = 收入 ÷ 订单数；单位成本 = 成本 ÷ 订单数。
- 这里的**毛利只是收入减成本，不是净利润**；未扣除获客、房租、人工、税费等费用。
- 原始文件未说明货币单位与收入口径（是否含税、运费、佣金），下文按同一单位的名义金额处理。

## 四、增长趋势

- 收入连续两月增长：10 月 +20.00%、11 月 +16.67%，9→11 月累计 +40.00%（20,000→28,000）。
- 成本累计 +30.77%（13,000→17,000），慢于收入增速，这是毛利率从 35.00% 升到 39.29% 的直接原因；毛利累计 +57.14%（7,000→11,000）。
- website 是增长主力：收入 +50.00%（12,000→18,000），毛利率 41.67%→47.22%，以 62.50% 的收入贡献 75.93% 的毛利。
- marketplace 收入 +25.00%（8,000→10,000），但毛利率停在 25.00%（10 月一度跌到 22.22%），单位成本从 60.00 升到 65.22；收入占比 40.00%→35.71%，毛利占比 28.57%→22.73%。
- 客单价由 90.91 升至 101.82（website 100.00→112.50，marketplace 80.00→86.96）；订单量 220→275（+25.00%）的贡献大于客单价（+12.00%）。

## 五、数据局限

1. 仅 3 个月、2 渠道、6 条记录，无季节性与波动信息，趋势不可外推。
2. 成本为单一合计，未拆分固定/变动成本、营销与履约费用，无法判断成本刚性。
3. 缺退货退款、折扣、税费、运费口径，"收入"是否净额不明；订单数不等于客户数。
4. 未标注货币单位，也未说明 2026-11 是否完整月。
5. 无历史基线、无新老客拆分、无流量转化数据，客单价提升原因无法归因。

## 六、三条行动建议

1. **加码 website**：它以 62.50% 的收入贡献 75.93% 的毛利且毛利率仍在上升。增量预算优先投向 website，并把该渠道毛利率不低于 45% 定为考核线。
2. **治理 marketplace 单位经济**：单位成本三个月升 8.70%（60.00→65.22），毛利率却原地踏步。先逐单复核平台佣金、履约与退货，再决定调价、争取佣金返还或砍掉低效订单；目标 4 周内毛利率 +3 个百分点。
3. **补齐数据与节奏**：在现有 CSV 增加退货退款额、营销费、客单价、新老客、流量与转化字段，按月固定口径出数；下季度设收入目标 ≥ 32,000（环比 ≥ +14%），同时监控毛利率不低于 38%。
